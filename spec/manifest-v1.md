# Eval Run Manifest v1

Fields: `run_id`, `timestamp`, `code_sha`, `env`, `rubric_ref`, `judge_card_ref`, `contamination_report_ref`, `dataset_card_refs`, `results_digest`, and optional `signature`.

`results_digest` is a SHA-256 digest over every relative path and file byte under the supplied run directory. The builder infers artifact references from conventional file names and does not check that fallback references exist.

`signature` may be `null`, a local deterministic digest object, or an attached Sigstore bundle object:

- `local-digest` is an integrity marker generated by hashing a literal key string and the canonical manifest digest. It is not an asymmetric signature and this package does not verify it.
- `sigstore-bundle` stores a pre-existing bundle alongside the canonical manifest digest. This package does not create or verify the bundle.

The current validator checks only that required top-level keys are present. Consumers that need type validation, reference existence, digest recomputation, or cryptographic verification must perform those checks separately.
